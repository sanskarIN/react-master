# Repository Governance

## Purpose

`react-master` is the public companion-code and engineering-reference repository for **React Full Mastery: Complete 150-Part Master Edition**.

## Authority boundaries

- Repository code/documentation may be open source under the applicable repository license.
- The commercial book manuscript and publication assets are not automatically open sourced by this repository.
- A README or folder placeholder must never be treated as proof that historical source exists.

## Change priorities

1. Correctness and reproducibility.
2. Security and privacy.
3. Accessibility and user experience.
4. Tests and build reliability.
5. Clear documentation and provenance.
6. Performance improvements supported by evidence.

## Historical-source policy

Recovered historical code must include a provenance note. Newly authored replacement code must be labeled as replacement/new work rather than historical recovery.

## Part numbering

Parts 001–150 are the complete numbered core series. Repository maintenance should not create Part 151 merely to continue numbering. New work should use repository releases, examples, labs, or clearly named supplemental directories.

## Stable identity

Use the repository URL and contact email as durable project references. Social profile links are intentionally not required for publication identity.
