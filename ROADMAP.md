# Companion Repository Roadmap

The React Full Mastery numbered core series is complete at Part 150. Repository development now focuses on making the companion materials more useful, reproducible, and maintainable.

## Phase 1 — Source recovery

- Recover genuine historical companion archives where available.
- Verify provenance before labeling files as recovered historical source.
- Keep unrecovered folders as documented placeholders.

## Phase 2 — Build quality

- Add explicit runtime and package-manager requirements.
- Add lockfiles where appropriate.
- Add lint, unit-test, accessibility-test, and build commands.
- Make `scripts/validate_all.py` cover every real package project.

## Phase 3 — Capstone completeness

- Prioritize major capstones and architecture workspaces.
- Add screenshots only when useful and free of personal/private data.
- Add sample data and fixtures with clear licenses.

## Phase 4 — Documentation

- Add architecture decision records.
- Add troubleshooting guides.
- Keep version-sensitive instructions linked to official documentation.
- Record errata and corrected examples.

## Phase 5 — Releases

- Publish stable repository releases such as `v1.0.0`, `v1.1.0`, etc.
- Keep changes granular and reviewable.
- Avoid commits whose only purpose is inflating the commit count.
- Keep the commercial manuscript outside public Git history.
